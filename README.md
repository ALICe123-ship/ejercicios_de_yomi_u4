# Festival Musical en Python

## Descripción


El programa simula un festival de música en el que participan distintos tipos de artistas. Cada artista se presenta, realiza su actuación y se despide del público. Para desarrollar este programa se implementan los conceptos de herencia, polimorfismo y constructores.

## Estructura del proyecto

- `artista.py` - Clase base Artista.
- `banda.py` - Clase Banda.
- `cantante.py` - Clase Cantante.
- `dj.py` - Clase DJ.
- `festival.py` - Función que inicia el festival.
- `main.py` - Programa principal.

## Conceptos utilizados

- Programación Orientada a Objetos.
- Herencia.
- Polimorfismo.
- Constructores.
- Clases y objetos.
